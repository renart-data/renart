Renart is an open source data platform for moving, transforming and analyzing
data across your data stack. Build and run SQL and Python pipelines alongside
notebooks and dashboards in one visual workspace, with type checking,
scheduling and everything defined as code in Git.

Bring a first-class developer experience to the entire data workflow: connect
your databases, warehouses, files, object storage and HTTP APIs, then build on
their data in the same workspace.

## Find your next task

- **Try Renart:** [install it](/docs/installation/) and follow the
  [local DuckDB quickstart](/docs/quickstart/).
- **Build a pipeline:** use the [asset editor](/docs/editing-assets/asset-editor/)
  and follow dependencies on the [canvas](/docs/workspace/pipeline-canvas/).
- **Connect your data:** check [supported platforms](/docs/reference/supported-platforms/)
  and [add a connection](/docs/connections-environments/managing-connections/).
- **Explore results:** combine sources in a [notebook](/docs/notebooks/overview/)
  or build a [dashboard or report](/docs/presentations/overview/).
- **Run on a schedule:** [review a deployment](/docs/scheduling/overview/),
  choose a cadence, and inspect [run history](/docs/workspace/runs-and-history/).

Authored definitions are version-controlled files. Run history, deployment
pins, and other machine-local state are stored separately; see
[How it works](/docs/how-it-works/).

:::note[Public alpha]
Renart is in public alpha. The core workflow is available, but expect rough
edges and changes before the first stable release. Read [what public alpha
means](/docs/alpha-status/) before relying on Renart for critical workloads.
:::

For orientation, start with [the interface tour](/docs/workspace/interface-tour/)
and [the main concepts](/docs/concepts/).
