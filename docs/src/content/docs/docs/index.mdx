Renart is an open source data platform for moving, transforming and analyzing
data across your data stack. Build and run SQL and Python pipelines alongside
notebooks and dashboards in one visual workspace, with type checking,
scheduling and everything defined as code in Git.

The goal is to bring a first-class developer experience to the entire data
workflow. Renart runs in your environment and connects to the databases,
warehouses, files, object storage and HTTP APIs you use.

## What you get

- **Data movement as part of the pipeline.** [Load assets](/docs/asset-types/load-assets/)
  move data between supported sources and destinations;
  [HTTP API assets](/docs/asset-types/http-api-assets/) bring API data into the workflow.
- **A pipeline canvas** that shows assets, dependencies, and freshness at a
  glance instead of making you reconstruct them from files by hand.
- **SQL and Python with development context.** Type checking and intelligent
  completion use known schemas and dependencies to help you edit and review code.
- **Preview, then materialize.** Preview SQL results with Inspect, then
  review and run materialization explicitly.
- **Catalog-aware SQL.** Complete against authored assets and observed remote
  tables, then review an import when an external relation should become part of
  the project.
- **Notebooks** that combine warehouses, files, object storage, and HTTP data
  in local DuckDB, with SQL, Python, text, controls, and checked charts.
- **Dashboards and reports** composed visually from typed datasets and stored
  as version-controlled definitions.
- **Reviewed deployments and schedules.** Pin a pipeline snapshot to each
  environment, run it on a cron, and inspect its timeline and logs.
- **Freshness you can see.** Renart fingerprints every asset and shows what's
  fresh, edited, stale, or never built, while external source assets remain
  explicitly neutral.

Authored definitions stay in your repository as plain, reviewable files.
Credentials, warehouse data and machine-local run history are separate from
those definitions. See [how Renart stores your work](/docs/how-it-works/).

:::note[Public alpha]
Renart is in public alpha. The core workflow is available, but expect rough
edges and changes before the first stable release. Read [what public alpha
means](/docs/alpha-status/) before relying on Renart for critical workloads.
:::
