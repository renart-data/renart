---
title: Dashboards and reports
description: Build checked dashboards and narrative reports from pipeline data on a visual canvas.
---

Dashboards and reports turn pipeline results into version-controlled views for
local analysis and review. You compose the result directly on a canvas, while
Renart checks the fields and types used by every visualization.

Both builders share the same **Data**, **Add**, and **Outline** tools, visual
settings inspector, chart-type previews, color palettes, and Definition editor.
An asset dataset gets its schema from the pipeline. A read-only SQL dataset uses
its selected connection's dialect, catalog completion, and inferred output
schema, so a renamed field or incompatible chart axis is caught before the
definition is saved.

## Build a dashboard

<img
  src="/docs-media/dashboard-builder.webp"
  alt="The Renart dashboard builder showing a revenue trend, KPI, category chart, filter controls, the Add rail, and visualization settings"
  width="3000"
  height="1920"
/>

1. Open **Dashboards** and click **New dashboard**.
2. Open **Data**, add a dataset, and choose a pipeline asset. A read-only query
   on a configured connection is also available for advanced cases.
3. Click **Add**. Choose one of the charts, KPIs, or tables suggested from the
   dataset's known columns.
4. Drag a tile by its handle and resize it from the lower corner. Select the
   tile to change its data, appearance, filter bindings, or accessible layout
   controls in the inspector.
5. Add controls from the filter strip. Text, select, multi-select, slider,
   range, and switch controls can use fixed values or options from a dataset.
   Changing a control refreshes only the visualizations bound to it.
6. Use the desktop, tablet, and mobile buttons to inspect the derived layout,
   then click **Save**.

The desktop grid is the saved layout. Tablet and mobile are predictable
previews of that layout, so there is no second hidden arrangement to maintain.

## Compose a report

<img
  src="/docs-media/report-builder.webp"
  alt="The Renart report builder combining narrative Markdown, a checked line chart, and a table in an ordered document"
  width="3000"
  height="1920"
/>

1. Open **Reports** and click **New report**.
2. Add a text block, then edit its heading and Markdown directly on the report
   page.
3. Add a dataset and insert checked visualizations between narrative blocks.
4. Drag blocks in the document or use **Move up** and **Move down**. Insert a
   page break where the printed report should continue on a new page.
5. Click **Save**, then **Preview** to see the clean audience view without
   editing controls.

## Work with drafts safely

Changes stay in a browser draft until you click **Save** or press
**Cmd/Ctrl+S**. Undo and redo work across text, layout, and component changes.
If you try to leave with unsaved work, Renart asks before discarding it.

The builder previews unsaved dataset and filter changes without writing an
incomplete definition to your repository. One compact command bar owns editor
mode, validation and preview state, history, refresh, preview, discard, and
save. Dashboard screen-size controls stay beside the canvas they affect. A
changed file is never silently merged into your draft; reload it and reconcile
the changes explicitly.

:::note
Saving a dashboard or report creates an ordinary reviewable repository change,
like editing an asset or notebook.
:::
